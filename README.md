# REDPOLY — Monsoon Mischief

**Original collectible creatures. Monsoon mischief, made to be collected.**

REDPOLY is a character-led collectible storefront, featuring four original creatures—Barsaat, Agni, Noor, and Aarav—with product pages, character art, and an origin-story comic.

**Website:** [redpoly.justsimpleapps.online](https://redpoly.justsimpleapps.online/)

## What's in this repository

- `index.html` — storefront landing page and featured collections
- `barsaat.html`, `agni.html`, `noor.html`, `aarav.html` — character-specific product pages
- `styles.css`, `product.css`, `main.js` — responsive styling and storefront interactions
- `CHARACTER-GUIDE.md` — canonical character descriptions and art direction
- `CHARACTER-IP-LICENSE.md` — restrictive use terms for REDPOLY character IP and artwork
- `assets/images/redpoly/characters/` — canonical character artwork
- `assets/images/redpoly/collections/` — approved collection-pose artwork
- `assets/images/redpoly/packaging/` — character packaging artwork
- `assets/images/redpoly/social/` — social sharing graphics
- `assets/images/redpoly/story/` — origin-story comic artwork
- `Sample Images/` — selected page screenshots and clearly named copies of the logo, favicon, and character artwork

## Run locally

Open `index.html` directly, or start a static server from the repository root:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000/>.

Prices shown are sample Indian-market prices in rupees.
