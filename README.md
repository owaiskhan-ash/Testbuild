# CHOMPKIT — Monsoon Mischief

Static collectible-creature landing page built with HTML, CSS and JavaScript (no build step).

- `index.html` — hero, Barsaat limited edition, four featured creatures, collections and crew/footer sections
- `styles.css` — responsive layout, creature package frames, color fields and subtle motion
- `main.js` — cart feedback in INR, wishlist hearts, crew form and reduced-motion-aware reveals
- `CHARACTER-GUIDE.md` — canonical character bible and visual consistency rules
- `assets/images/chompkit/{barsaat,agni,noor,aarav}.png` — canonical transparent-alpha character art, reused consistently across the site

Display prices are sample Indian-market prices in rupees: ₹3,299 standard and ₹4,099 limited edition. Open `index.html` directly or serve with any static server (for example `python3 -m http.server`).
