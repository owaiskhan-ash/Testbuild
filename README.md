# REDPOLY — Monsoon Mischief

Static collectible-creature landing page built with HTML, CSS and JavaScript (no build step).

- `index.html` — REDPOLY hero, Barsaat limited edition, four featured creatures, collections and footer
- `styles.css` — responsive layout, creature display frames, face portraits and expressive motion
- `main.js` — cart feedback in INR, wishlist hearts, crew form, kinetic text and reduced-motion-aware reveals
- `CHARACTER-GUIDE.md` — canonical character bible and visual consistency rules
- `assets/images/redpoly/characters/` — four canonical transparent-alpha character PNGs reused across the site
- `assets/images/redpoly/footer-faces/` — transparent close-up crops from those same canonical PNGs for the footer

Display prices are sample Indian-market prices in rupees: ₹3,299 standard and ₹4,099 limited edition. Open `index.html` directly or serve with any static server (for example `python3 -m http.server`).
