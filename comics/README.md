# Comics

Keep each comic in its own numbered issue folder, such as `issue-002-short-title/`. Store its metadata (`issue.json`) and production notes with the issue, and name optimized finished page art sequentially (`pages/page-01.webp`, `pages/page-02.webp`, and so on), plus a small `cover.webp` preview. Add reader-ready issue metadata to `catalog.json`. Issue 01 is the first complete six-page story; its original homepage storyboard is retained with the issue.
