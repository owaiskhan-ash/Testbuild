# Comics

Keep each comic in its own numbered issue folder, such as `issue-002-short-title/`. Store its metadata (`issue.json`) and production notes with the issue, and name finished page art sequentially (`pages/page-01.png`, `pages/page-02.png`, and so on). Add reader-ready issue metadata to `catalog.json`. Issue 01 is the first complete six-page story; its original homepage storyboard is retained with the issue.
